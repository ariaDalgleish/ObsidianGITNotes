Procedure: As the evaluator assess the system and note any violations of these heuristics that would indicate a potential usability problem. 
Assess the severity of each usability problem based on:
- How common is the problem?
- How easy is it for the user to overcome?
- Will it be a one-off problem or a persistent one?
- How seriously will the problem be perceived?

Complete independent assessment of all problems collected and the severity ratings. 
0 = I don't agree this is a usability problem at all
1 = Cosmetic problem only: need not be fixed unless extra time is available on project
2 = Minor usability problem: low priority
3 = Major usability problem: important to fix, high priority
4 = Usability catastrophe: imperative to fix before product can be released (Nielsen)
