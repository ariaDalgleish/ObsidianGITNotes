**Keystroke-level Model**.
Benchmark the performance by calculating the time it'll take for person to perform the task, the different steps to go through the sequence. 
This task might take 30 secs but using different application it might take 40 secs. 

- K: Keystroke, mouse click, button press
- Pointing: Moving the mouse to the target (clicking is a keystroke)
- Homing: Moving hand from/to mouse and keyboard. 
	- Left hand or right hand
- Drawing: Dragging the mouse in straight-line segments
- Mental preparation: Mentally preparing for executing physical actions. Time user needs for thinking or decision making which depends on the knowledge and skill of the user.
- Response Time: The response time of the system depends on the system, the command and the context of the command. It is only used when the user actually has to wait for the system > System Dependent.

**Fitts' Law**

How much time it takes for our fingers to move from one point to another. 
Uncomfortable movements - design interface to pick up on these things. Might be very small inconvenience but the user will pick it up, over time it'll become a real problem.
